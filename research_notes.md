# External guidance notes

1. OWASP Application Security Verification Standard (ASVS): OWASP describes ASVS as a basis for testing web application technical security controls and as a list of secure-development requirements. It can be used as a metric, guidance, and procurement baseline. Source: https://owasp.org/www-project-application-security-verification-standard/

2. India Digital Personal Data Protection Act, 2023: official Ministry of Electronics and Information Technology PDF. The project handles student/staff identifiers, contact data, authentication data, attendance, marks, and submissions; therefore it should define data inventory, purpose/retention, access controls, correction/deletion workflows where applicable, breach response, and vendor/data-processing responsibilities with the institution. Source: https://www.meity.gov.in/static/uploads/2024/06/2bf1f0e9f04e6fb4f8fef35e82c42aa5.pdf

3. NIST ransomware/data-loss guidance: backups should be protected and tested, not merely created. This supports recommending tested restore procedures, retention, and off-site/independent backup for academic records. Source: https://csrc.nist.gov/pubs/other/2020/04/24/protecting-data-from-ransomware-and-other-data-los/final
